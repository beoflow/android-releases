# Beoflow Android QA builds

Every merge to `dev` of the Beoflow Android app publishes a QA APK here.

**Latest build:** [beoflow-qa-latest.apk](https://github.com/beoflow/android-releases/raw/main/beoflow-qa-latest.apk) — 1.0.14-qa.127, commit `45f1666`

- Talks to the production Beoflow backend; sign in with your normal account.
- Installs as `com.beoflow.ios.debug`, next to the Play Store app.
- Open the link on the phone, allow your browser to install unknown apps once, then install.

Every build is also kept as a tag (`qa-<build number>`).
